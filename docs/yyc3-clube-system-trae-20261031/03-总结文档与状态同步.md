## 四、问题与解决方案

| 问题 | 解决方案 | 经验教训 |
| --- | --- | --- |
| `/dashboard/reports/artist` 首次 500 | Server Component 向 Client Component 传 `LucideIcon` 不可序列化；页面改为 `"use client"` | 图标作为 props 跨 RSC 边界时，要么客户端页面，要么传名称 |
| 默认日期筛选导致初始行数变化 | `DatePickerWithRange` 挂载即回调最近 7 天；据此校验 16 行 | 报表验收要区分 SSR 初始数据与挂载后筛选 |
| 测试脚本无法找到 Playwright | `/tmp` 找不到项目依赖 | 使用绝对路径或放入项目内运行 |
| 离线安装缺 tarball | 根工作区单独安装 `--filter . --prefer-offline` | 多 workspace 安装需按包过滤 |
| Recharts 升级后类型报错 | `Tooltip.labelFormatter` 参数变为 `ReactNode` | 升级依赖后必须跑全量 type-check，及时修复 API 类型漂移 |
| pnpm 12 不再读取 `package.json#pnpm.overrides` | overrides 被忽略 | 安全 overrides 应放在 `pnpm-workspace.yaml` |
| Next 16 构建报 138 处 React 未使用 | 自动 JSX 运行时下 `import * as React` 冗余 | 批量移除仅 JSX 使用的 React 导入 |
| 移除无效 `@ts-ignore` 暴露 10 个未使用成员 | 注释掩盖了真实 TS6133 | 清理未使用字段/方法为 public，而非继续屏蔽 |
| `next start` 不支持 standalone | 启动脚本与实际产物不匹配 | `start` 改为 `node .next/standalone/server.js` + 静态资源复制 |
| 删除 npm 锁文件后安全用例 3 条失败 | 旧断言仍读取 `package-lock.json`、`npm audit`、`>=1.3.1` | 安全用例改为校验 pnpm-lock、`pnpm audit --prod` 与 overrides 最低安全版本 |
| 组件测试报 “Element type is invalid” | `jest.setup.ts` 的 framer-motion mock 仅含 div/button/span，`motion.tr` 为 undefined | mock 补齐 `tr`；新增表格类组件测试时同步检查 mock 元素清单 |
| Playwright 访问 `127.0.0.1` 反复 HMR 失败且模块不热更 | Next 16 默认阻止跨源 dev 资源，`allowedDevOrigins` 未含 127.0.0.1 | 本地验证统一用 `http://localhost:3030`；如需 127.0.0.1 需在 `next.config.mjs` 加白名单 |
