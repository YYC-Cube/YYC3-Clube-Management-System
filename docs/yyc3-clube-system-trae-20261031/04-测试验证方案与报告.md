- 结算层：部分结算、跨月结算、撤销后重算。

## 六、测试通过标准与失败判定

**通过标准**：

1. 所有 P0 用例通过。
2. 新增/修改文件 `tsc` 0 error、ESLint 0 error。
3. 单测 100% 通过。
4. 页面无 `console.error` / `pageerror`。
5. 金额勾稽与结算勾稽 100% 一致。

**失败判定**：

- 任一 P0 用例失败；
- 勾稽差额 ≠ 0；
- 页面 5xx；
- 导出文件列缺失/乱码；
- 新增类型错误或 lint error。
